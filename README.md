#Case Study 3
# Sentiment Analysis on Product Reviews using BERT and LSTM

## Project Overview
This project performs sentiment analysis on Amazon Fine Food Reviews using Natural Language Processing (NLP) techniques.

The goal is to classify customer reviews into three sentiment categories: Positive, Neutral, and Negative.

## Dataset
- **Source:** Kaggle – Amazon Fine Food Reviews
- **Features:** Review Text and Score

## Technologies Used
- Python
- Pandas, NumPy
- TensorFlow / Keras
- Hugging Face Transformers
- Scikit-learn
- Matplotlib, Seaborn

## Models Implemented
- BERT (Fine-tuning)
- LSTM (Baseline model)

## Evaluation
Models are evaluated using accuracy, precision, recall, F1-score, and confusion matrices.

## How to Run
1. Open the notebook in Google Colab.
2. Install the required libraries.
3. Run the cells sequentially.

#Case Study 4
# E-Commerce Customer Segmentation using Machine Learning

## Project Overview
This project segments e-commerce customers based on their purchasing behaviour using RFM analysis and unsupervised machine learning algorithms.

## Dataset
- **Source:** Kaggle – Customer Segmentation Dataset
- **Features:** Customer transaction details

## RFM Analysis
- Recency
- Frequency
- Monetary

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib

## Algorithms Implemented
- K-Means Clustering
- DBSCAN
- Principal Component Analysis (PCA)
- t-SNE

## Evaluation
Silhouette Score and cluster analysis are used to evaluate customer segments.

## Outcome
Customer groups are interpreted into marketing personas such as high-value customers, regular customers, and low-value customers.

## How to Run
1. Open the notebook in Google Colab.
2. Install the required libraries.
3. Run the cells sequentially.
